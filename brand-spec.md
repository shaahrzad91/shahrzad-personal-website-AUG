# Shahrzad Amin Ranjbar - Personal Brand System

The system pairs an ivory editorial canvas and powder-blue structure with deep navy type, using pale yellow as a rare moment of warmth.

## Core tokens

```css
:root {
  --bg: oklch(0.985 0.012 96);
  --surface: oklch(0.955 0.032 231);
  --fg: oklch(0.235 0.052 257);

```

## Typography

- Display: `"Iowan Old Style", "Palatino Linotype", Palatino, Georgia, serif`
- Body: `"Avenir Next", Avenir, "Segoe UI", Helvetica, sans-serif`
- Mono: `"SFMono-Regular", Consolas, "Liberation Mono", monospace`

## Posture rules

1. Use an editorial serif for personal statements and major section titles; use the humanist sans for navigation, technical detail, and interface controls.
2. Keep the canvas warm and quiet. Powder blue marks structure; pale yellow appears only as a small highlight or primary action.
3. Prefer asymmetric, generously spaced layouts with rounded but not pill-like cards and subtle cool-toned shadows.
4. Express AI through data relationships, layered geometry, and motion - never robots, brains, neon glows, or stock photography.
5. Tell experience and projects as concise narratives, always separating verified facts from editable placeholders.
